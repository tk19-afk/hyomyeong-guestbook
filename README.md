# 🏫 효명고 교원 방명록 앱 (Hyomyeong Guestbook)

> **"에이전트와 함께하는 학교 방명록 앱 개업기"**  
> 효명고등학교 동료 교원들을 위한 안전하고 따뜻한 실시간 소통 웹 애플리케이션입니다.

---

## 🌟 주요 특징 및 기능

1. **학교 전용 출입문 (`@hmh.or.kr` 도메인 제한)**
   - 효명고 교원 계정으로만 구글 로그인이 승인되며, 외부 계정 접속 시 친절한 안내와 함께 자동 차단됩니다.
2. **구글 프로필 이름 & 익명 선택 토글**
   - 로그인 시 선생님의 성함이 자동으로 작성자로 지정됩니다.
   - 솔직하거나 가벼운 응원을 남기고 싶을 때는 언제든 `[익명으로 남기기]`를 체크할 수 있습니다.
3. **Tenor 실시간 움짤(GIF) 키워드 검색**
   - 방명록 글에 원하는 키워드(예: `박수`, `칼퇴`, `화이팅`, `감동`, `커피` 등)를 검색하여 생동감 넘치는 반응 움짤을 첨부할 수 있습니다.
4. **Google Firebase 실시간 동기화**
   - 동료 선생님이 글을 남기는 즉시 새로고침 없이 전 세계/모든 기기에서 실시간으로 피드가 갱신됩니다.
